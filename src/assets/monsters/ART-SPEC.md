# 单词怪美术素材规格 (Monster Art Spec)

战斗采用回合制交战：一波 6–8 只单词怪，每只怪的**难度分级**由它对应单词的
**生僻度（词频位次）+ 字母长度**共同决定，视觉上要一眼看出强弱。

## 通用规格（所有怪通用）

- **画布**：1024 × 1024 像素，正方形。
- **格式**：PNG-32（RGBA），**背景透明**，不要白底/纯色底。
- **构图**：角色水平居中；脚部落在画面下部约 3/4 处；主体占画布高度约 85%，
  顶部留少量空白。**同一只怪的 4 个姿态必须锚点一致**（同样的缩放与位置），
  否则切换姿态会“跳动”。
- **朝向**：与现有 `grunt/` 一致——**面向左侧**（玩家/卷王在左）。
- **风格**：与现有 `grunt/`、`boss/` 一致（卡通、粗描边、扁平赛璐珞上色、
  高饱和），在屏幕上约 120–180px 也要清晰可辨。

## 每只怪需要 4 张姿态图（文件名固定）

| 文件名 | 触发时机 |
| --- | --- |
| `idle.png` | 在队列里待机 |
| `attack.png` | 轮到它出招（对玩家发起攻击 = 出题时）|
| `hurt.png` | 玩家答对、被击中的瞬间 |
| `defeated.png` | 被击败倒下 |

## 难度分级 → 目录 → 视觉建议

四档常规怪 + 一档波次首领。目录已建好，把对应 4 张图放进去即可：

| 档位 | 目录 | 对应单词 | 体型/配色建议 |
| --- | --- | --- | --- |
| T1 幼卒 common | `grunt/`（已存在，可沿用/重绘） | 高频短词 | 小、圆润、可爱、绿/黄暖色 |
| T2 游兵 uncommon | `uncommon/` ← 待生成 | 中频/中长词 | 略大、稍凶、蓝/青冷色 |
| T3 悍将 rare | `rare/` ← 待生成 | 低频或较长词 | 更大、带甲/尖刺、紫色系 |
| T4 妖将 elite | `elite/` ← 待生成 | 生僻长词/学术词 | 最大、狰狞、暗红/黑金、发光眼 |
| BOSS 词魔王 | `boss/`（已存在） | 每波最难词/首领 | 巨型，另用 `phase-1/2/3 + defeated` |

> “灵活组合”建议：四档可共享同一族生物骨架，靠**体型 + 配色 + 装饰（甲片/尖刺/
> 光效）**区分强弱；如需子级变体，做同档的调色版本即可，文件名与姿态保持一致。

## 优化流程（重要）

源 PNG 只是**本地母版**，`src/assets/**/*.png` 已被 gitignore，不会进仓库、也不会
打进网站包。放好 PNG 后运行：

```bash
npm run assets:optimize            # 全部 PNG → WebP，最长边 512px（一排小怪足够）
npm run assets:optimize -- --max 1024   # 需要大图时（当前单怪模式的 grunt/boss）
```

脚本会在每个 PNG 旁生成同名 `.webp`；**应用只引用 `.webp`，提交的也只是 `.webp`**。
新怪默认压到 512px（每张约 30–50KB，比 1024 PNG 小 ~96%）。
